# MediaMTX Binary

Download the latest Linux amd64 release (v1.9+) from:
https://github.com/bluenviron/mediamtx/releases

Extract `mediamtx` into this folder (`poc/mediamtx/mediamtx`) and run:
```bash
chmod +x mediamtx
```

The backend (`poc/backend/mediamtx.py`) automatically generates `mediamtx.yml` and manages the `mediamtx` subprocess.
